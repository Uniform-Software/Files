# UniFiles 0.2.2

- **Nouvelle icône**, et le dossier de sortie (Documents/UniFiles) prend l'icône de dossier UniFiles dans le Finder et l'Explorateur.
- **Logo** épuré : le mot « unifiles » seul, dans sa police.
- **Afficher dans le Finder / l'Explorateur** : à la fin d'un traitement, le bouton ouvre le dossier avec le fichier produit déjà sélectionné.
- **Glisser les résultats** : depuis la file d'attente, fais glisser les fichiers traités directement dans un e-mail, une discussion ou un autre dossier.
- Les téléchargements de la publication sont plus robustes (nouvelles tentatives en cas de coupure).
