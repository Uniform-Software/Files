# UniFiles 0.2.1

Des finitions pour la 0.2.

- **Mise à jour en un clic** : quand une nouvelle version est prête, un bouton « Mettre à jour vers … » apparaît en bas de la barre latérale. Si des fichiers sont en cours de traitement, la mise à jour attend qu'ils soient finis. Sinon, elle s'installe toujours quand tu quittes UniFiles.
- **Compression plus lourde que l'original** : si un fichier est déjà optimisé, UniFiles garde l'original au lieu d'un résultat plus gros, et le signale dans la file d'attente et l'aperçu.
- **Préréglages** : leurs réglages s'affichent au survol, et un crayon permet de les renommer.
- **macOS** : textes adaptés (barre des menus, ⌫) et raccourcis avec ⌘ (⌘Z pour annuler, ⌘↩ pour lancer).
- **Interrupteurs** : le rond devient foncé quand ils sont activés, pour mieux se lire sur le vert.
