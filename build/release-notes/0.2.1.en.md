# UniFiles 0.2.1

Finishing touches for 0.2.

- **One-click update**: when a new version is ready, an "Update to …" button appears at the bottom of the sidebar. If files are being processed, the update waits for them to finish. Otherwise, it still installs when you quit UniFiles.
- **Compression heavier than the original**: if a file is already optimized, UniFiles keeps the original instead of a bigger result, and says so in the queue and the preview.
- **Presets**: their settings show on hover, and a pencil lets you rename them.
- **macOS**: texts adapted to the Mac (menu bar, ⌫) and shortcuts with ⌘ (⌘Z to undo, ⌘↩ to start).
- **Switches**: the knob turns dark when they're on, to read better on the green.
