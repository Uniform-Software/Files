# UniFiles 0.1.0

Première version publique de UniFiles pour Windows. Glisse. Dépose. C'est fait.

- **Images** : compresser, redimensionner, convertir (PNG, JPG, WebP, AVIF), supprimer les métadonnées.
- **Renommage** par modèle avec aperçu avant/après.
- **PDF** : fusionner, découper, images vers PDF, compresser.
- **Vidéo / audio** : éditeur de coupe en plusieurs passages, compresser, convertir, extraire l'audio.
- Clic droit dans l'Explorateur (à activer dans les Préférences), icône dans la zone de notification.
- 100 % local : aucun fichier ni aucune donnée ne quitte ton ordinateur.

Cette version n'est pas encore signée : Windows peut afficher « Windows a protégé votre ordinateur ». Clique sur « Informations complémentaires », puis sur « Exécuter quand même ».
