# UniFiles 0.3.0

- **PDF forms**: fill in an existing form right inside UniFiles (text, check boxes, radio buttons, lists), add simple fields to any PDF to make a sign-up sheet, and flatten the result to lock the answers in. Two quick actions: **Flatten a form** and **Export answers to CSV** (a spreadsheet with one row per filled PDF).
- **Action chains**: "Resize, then compress, then convert to WebP" in one go, and it can be saved as a preset.
- **Watched folders** (new Automations page): every file dropped into a folder is processed with a preset, then the original is kept, moved to "Processed" or sent to the trash. Option to start UniFiles when you log in.
- **Choose the output folder** when you start: the usual folder, next to the originals, a dated subfolder or another folder. The structure of dropped folders can be kept.
- **New actions**: PDF to images, Remove PDF metadata, Normalize loudness, Mute a video, and a new **Files** module with Create a ZIP archive.
- **Paste to process**: Cmd/Ctrl+V pastes copied files or a screenshot.
- **Do again from the history**: runs the same action, with the same settings, on other files.
- **What's new and licenses in the app**: release notes and third-party licenses open in a UniFiles window (Preferences), and what's new shows once after each update.
