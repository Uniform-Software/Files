# UniFiles 0.1.0-alpha

Première version de test de UniFiles, pour Windows et macOS. Glisse. Dépose. C'est fait.

- **Images** : compresser, redimensionner, convertir (PNG, JPG, WebP, AVIF), supprimer les métadonnées.
- **Renommage** par modèle avec aperçu avant/après.
- **PDF** : fusionner, découper, images vers PDF, compresser.
- **Vidéo / audio** : éditeur de coupe en plusieurs passages, compresser, convertir, extraire l'audio.
- Windows : clic droit dans l'Explorateur (à activer dans les Préférences), icône dans la zone de notification.
- macOS : « Ouvrir avec → UniFiles » dans le Finder, dépôt sur l'icône du Dock, icône dans la barre des menus. Pour compresser un PDF, installe Ghostscript avec Homebrew (`brew install ghostscript`).
- 100 % local : aucun fichier ni aucune donnée ne quitte ton ordinateur.

Cette version n'est pas encore signée.
- Windows peut afficher « Windows a protégé votre ordinateur » : clique sur « Informations complémentaires », puis sur « Exécuter quand même ».
- macOS refuse d'abord de l'ouvrir : va dans Réglages Système → Confidentialité et sécurité, puis clique sur « Ouvrir quand même ».
