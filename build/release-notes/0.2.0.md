# UniFiles 0.2.0

Glisse. Dépose. C'est fait — et maintenant, en un clic.

- **Préréglages** : enregistre une action et ses réglages sous un nom (« Site web 1600 px », « Envoi mail »), puis relance-les en un clic depuis l'écran d'action ou le clic droit.
- **Tailles cibles** : « moins de 500 Ko » pour une image, « 10 Mo pour Discord » ou « 25 Mo pour un e-mail » pour une vidéo. UniFiles trouve la meilleure qualité qui tient dans la taille.
- **Photos iPhone (HEIC)** vers JPG ou PNG, en gardant les infos de la photo. Tous les outils images acceptent maintenant le HEIC.
- **Aperçu avant/après** des images : le vrai résultat sur un fichier, avec une poignée à faire glisser, le poids réel et un mode 100 %.
- **PDF : organiser les pages** : réordonne par glisser-déposer, fais pivoter ou retire des pages.
- **GIF animé** depuis l'éditeur de coupe vidéo.
- **Encodage vidéo matériel** : compressions, conversions et coupes plusieurs fois plus rapides avec la puce vidéo de l'ordinateur (désactivable dans les Préférences).
- **macOS** : les actions et tes préréglages dans les « Actions rapides » du clic droit du Finder (à activer dans les Préférences).
- **Mises à jour automatiques** : les prochaines versions se téléchargent en arrière-plan et s'installent quand tu quittes UniFiles. C'est le seul accès réseau de l'appli, désactivable dans les Préférences.

Corrigé : compresser, redimensionner ou convertir une photo HEIC échouait.

Cette version n'est pas encore signée.
- Windows peut afficher « Windows a protégé votre ordinateur » : clique sur « Informations complémentaires », puis sur « Exécuter quand même ».
- macOS refuse d'abord de l'ouvrir : va dans Réglages Système → Confidentialité et sécurité, puis clique sur « Ouvrir quand même ».

Les versions 0.1 n'ont pas encore de mise à jour automatique : installe celle-ci par-dessus (Windows) ou remplace l'appli dans le dossier Applications (macOS).
