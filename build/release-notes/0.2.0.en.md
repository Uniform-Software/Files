# UniFiles 0.2.0

Drag. Drop. Done — and now in one click.

- **Presets**: save an action and its settings under a name ("Website 1600 px", "Email"), then run them again in one click from the action screen or the right-click menu.
- **Target sizes**: "under 500 KB" for an image, "10 MB for Discord" or "25 MB for an email" for a video. UniFiles finds the best quality that fits.
- **iPhone photos (HEIC)** to JPG or PNG, keeping the photo's details. Every image tool now accepts HEIC.
- **Before/after preview** for images: the real result on a file, with a handle to drag, the actual size and a 100% mode.
- **PDF: organize pages**: reorder by drag and drop, rotate or remove pages.
- **Animated GIF** from the video trim editor.
- **Hardware video encoding**: compressions, conversions and trims several times faster with the computer's video chip (can be turned off in Preferences).
- **macOS**: the actions and your presets in the Finder's right-click "Quick Actions" (turn them on in Preferences).
- **Automatic updates**: new versions download in the background and install when you quit UniFiles. It's the app's only network access, and it can be turned off in Preferences.

Fixed: compressing, resizing or converting a HEIC photo failed.

This version isn't signed yet.
- Windows may show "Windows protected your PC": click "More info", then "Run anyway".
- macOS refuses to open it at first: go to System Settings → Privacy & Security, then click "Open Anyway".

Versions 0.1 don't update automatically yet: install this one over it (Windows) or replace the app in the Applications folder (macOS).
