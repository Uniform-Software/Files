# UniFiles 0.1.0

First public release of UniFiles for Windows. Drag. Drop. Done.

- **Images**: compress, resize, convert (PNG, JPG, WebP, AVIF), remove metadata.
- **Renaming** with a pattern and a before/after preview.
- **PDF**: merge, split, images to PDF, compress.
- **Video / audio**: trim editor with several segments, compress, convert, extract the audio.
- Right-click menu in File Explorer (turn it on in Preferences), icon in the notification area.
- 100% local: no file and no data ever leaves your computer.

This version isn't signed yet: Windows may show "Windows protected your PC". Click "More info", then "Run anyway".
